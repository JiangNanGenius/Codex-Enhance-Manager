# Codex Enhanced Manager v2.3.0

## 中文

v2.3.0 保留 Windows 版本并新增 Apple Silicon macOS 12+ 版本。主要更新包括模型级上游路由/上下文/压缩阈值/服务档位、Web Search 与 Responses Lite 目录元数据、VLM 图片策略、音频转写、本地脚本/主题/桌宠、可撤销批量会话删除、多数据库发现，以及显式 worktree / Zed Remote 工作流。

macOS 资产名为 `CodexEnhancedManager-v2.3.0-macos-arm64.dmg`，使用 ad-hoc 签名且未做 Apple 公证。首次打开请核对 SHA-256，然后通过 Control 点按“打开”或“系统设置 → 隐私与安全性 → 仍要打开”。

按本次发布约定，没有执行单元测试、pytest、lint、语法检查、冒烟、手工启动、本地构建或安装包验证。只完成静态逻辑与最终差异审查。GitHub Actions 只负责打包并计算大小/SHA-256；若 CI 失败，本 Release 可能暂时只有源码。

## English

v2.3.0 keeps the Windows build and adds Apple Silicon macOS 12+ support. Highlights include per-model upstream routing/context/compact limits/service tiers, Web Search and Responses Lite catalog metadata, VLM image policies, audio transcription forwarding, local scripts/themes/pets, recoverable batch session deletion, multi-database discovery, and explicit worktree/Zed Remote workflows.

The macOS asset is `CodexEnhancedManager-v2.3.0-macos-arm64.dmg`. It is ad-hoc signed and not notarized. Verify its SHA-256 before using Control-click → Open or System Settings → Privacy & Security → Open Anyway.

Per the release instruction, no unit tests, pytest, lint, syntax checks, smoke tests, manual launches, local builds, or installer verification were performed. Only static logic and final diff review were completed. GitHub Actions only packages artifacts and records size/SHA-256; if CI fails, this Release may temporarily contain source archives only.
